# 银龄英语 · 开口说 🇨🇳🇬🇧

一个专为 **零基础老年人** 设计的英语开口学习小网站：大字、大按钮、慢速朗读，跟着读、录下来，让电脑告诉你读得怎么样。

在线使用：<https://cwl128.github.io/slow-english-learning/>

## ✨ 功能

- **看单词**：5 个生活主题、40 个高频单词 / 短句，每个都配中文意思和可选的“中文谐音”记忆帮手。
- **听读音**
  - 🔊 整句慢速朗读
  - 🐢 **一个词一个词读**：每个词之间停一下、并高亮当前读到的词，听得更清楚
  - 点任意单词小片，单独听那个词
- **录音跟读**：点红色麦克风 🎤 开始录音，大声读一遍，再点一次结束（也会自动结束）。
- **电脑听 + 发音反馈**
  - 显示电脑听到的英文
  - 逐词用颜色反馈：🟢 读得好 / 🟠 接近了 / 🔴 再练练（点彩色词可再听老师读）
  - 打分（100 分制 + 星星），并给出一句鼓励的话
  - 可以回放“自己读的”，对照老师的读音
- **为老人做的细节**
  - 默认慢速、大字（设置里可调更大 / 特大），自动挑选自然清晰的英文声音
  - 每页返回按钮很大，三步学习法引导清晰
  - 学完一课有星星总结和鼓励
  - 支持键盘 Esc 关闭弹窗、减少动画的“减弱动态效果”

## 🚀 本地运行

```bash
cd english-for-seniors
python3 -m http.server 8000
```

然后用电脑上的 **Chrome 或 Edge** 浏览器打开：`http://localhost:8000`

> 老人使用时，请把网页放到**大屏幕**或平板，并打开声音。

## 🌐 浏览器要求

- 听读音：Chrome / Edge / Safari 均可（使用系统自带的英文语音）。
- **电脑听读音（发音反馈）**：需要 **Chrome 或 Edge**，并允许麦克风权限；其它浏览器可以录音回放，但没有自动发音反馈。
- 语音识别会把这句话的音频交给浏览器提供的在线识别服务（Chrome 默认使用 Google 服务），录音本身不离开你的电脑、不发送到任何本网站服务器。介意的话可以关掉自动反馈，只用“听 + 录音回放”练习。

## 📁 文件说明

```
english-for-seniors/
├── index.html        页面结构
├── css/styles.css    样式（大字、暖色、大按钮）
├── js/data.js        课程内容（想加单词改这里）
├── js/app.js         朗读、录音、识别、反馈逻辑
└── README.md         本说明
```

想增加课程：打开 `js/data.js`，照着现有格式往 `LESSONS` 里加一个 `{ id, title, sub, icon, items:[...] }` 即可，首页会自动出现新课卡片。

## ⚠️ 已知限制

- 语音识别是“电脑听”的结果，不是绝对标准，识别本身可能出错；请把它当作参考，多听多读最重要。
- 第一次点麦克风，浏览器会询问“是否允许使用麦克风”，请点 **允许**。
